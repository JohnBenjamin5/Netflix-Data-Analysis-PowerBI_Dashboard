Overview:
This project focuses on analyzing Netflix Movies and TV Shows using Microsoft Power BI. An interactive dashboard was developed to transform raw Netflix data into meaningful insights through data visualization and analysis.The dashboard provides insights into content distribution, ratings, genres, directors, country-wise availability, and release-year trends.

 Dashboard Features:
•	Total Shows: Displays the total number of Netflix titles.
•	Rating Analysis: Analyzes content distribution by rating categories.
•	Genre Analysis: Identifies popular genres on Netflix.
•	Director Analysis: Displays the number of directors represented.
•	Country-wise Analysis: Visualizes content distribution across countries.
•	Movies vs TV Shows: Compares Movies and TV Shows.
•	Release Year Analysis: Shows content release trends over time.
•	Year Range Slicer: Allows users to filter content by release year.

Tools & Technologies:
•	Microsoft Power BI
•	Power Query
•	DAX (Data Analysis Expressions)
•	Data Cleaning and Transformation
•	Data Visualization

 Key Insights:
•	Compared the distribution of Movies and TV Shows.
•	Identified frequently occurring content ratings.
•	Explored popular genres and content categories.
•	Analyzed the geographical distribution of Netflix titles.
• Examined Netflix content release trends across different years
